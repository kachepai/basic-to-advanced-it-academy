# Basic To Advanced IT Academy — Starter Website

এটি আপনার Academy website-এর প্রথম starter version।

## কী কী আছে
- Responsive Home page
- আপনার দেওয়া profile photo
- Live Courses section
- Recorded Courses section
- About section
- Contact section
- Mobile menu
- Course cards
- আপনার Academy নাম: Basic To Advanced IT Academy

1. আপনার আসল logo
2. আপনার নিজের পরিচয়/বায়ো
3. আসল Live Course-এর নাম, fee, duration
4. Recorded Course
5. WhatsApp number
6. Facebook Page
7. YouTube channel
8. Registration form
9. প্রতিটি course-এর আলাদা details page
